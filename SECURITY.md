# Security Policy / 安全策略

## Reporting a vulnerability / 报告漏洞

Please **do not** open a public issue for security problems. Use GitHub's private
vulnerability reporting instead: **Security → Report a vulnerability** on this repository.

请不要用公开 issue 报告安全问题，改用本仓库的 **Security → Report a vulnerability**（私密漏洞报告）。

Include the affected version, steps to reproduce and the impact you expect. We aim to
acknowledge reports within 7 days.

## Supported versions / 支持的版本

Only the latest release receives security fixes. / 只有最新发布版会收到安全修复。

## Scope / 范围

Paper Field is a local desktop app. In scope: the app's code in this repository, its
handling of untrusted content (paper metadata, PDFs, LLM output, imported backups) and the
release pipeline. Your own LLM / MinerU providers and their accounts are out of scope.
